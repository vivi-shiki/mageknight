# Mage Knight Web

[English](README.md) · **简体中文** · [日本語](README.ja.md)

一个规则自动执行的《法师骑士》(Mage Knight) 风格单人网页游戏：探索六边形地图，组合手牌产生移动、交涉、攻击和格挡，在日夜交替与法力的时间压力下完成场景目标、挑战首领。

> 本项目为个人爱好作品，与 WizKids 及原版桌游权利方无关。卡牌和版图使用占位美术，不包含任何官方图片素材。

## 功能

- **教学关卡**：固定剧本的入门关卡，帮助熟悉基本玩法
- **单人征服 (Solo Conquest)**：四位原版英雄及 Braevalar，完整牌池、市场、单位招募、技能与神器
- **扩展内容**：原版、Lost Legion、Krang、Shades of Tezla 可单独或组合启用
- **存档与回放**：在浏览器本地存档，支持撤销，并可回放已完成的对局
- **多端适配**：以桌面为主，平板和手机也能玩
