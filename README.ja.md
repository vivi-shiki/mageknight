# Mage Knight Web

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

『メイジナイト』(Mage Knight) 風のソロ用ブラウザゲームで、ルールは自動で処理されます。ヘックスマップを探索し、手札を組み合わせて移動・交渉・攻撃・防御を生み出し、昼夜の移り変わりとマナの制約の中でシナリオ目標とボス戦に挑みます。

> 本プロジェクトは個人の趣味による作品で、WizKids および原作ボードゲームの権利者とは関係ありません。カードやタイルは仮のグラフィックを使用しており、公式の画像素材は含まれていません。

## 機能

- **チュートリアル**：基本を覚えるための固定シナリオ
- **ソロ征服 (Solo Conquest)**：基本セットの英雄 4 人と Braevalar、全カード、オファー、ユニット雇用、スキル、アーティファクトに対応
- **拡張**：基本セット、Lost Legion、Krang、Shades of Tezla を単独または組み合わせて使用可能
- **セーブとリプレイ**：ブラウザ内にローカル保存、手戻し（アンドゥ）、終了したゲームのリプレイ
- **マルチデバイス対応**：デスクトップを中心に、タブレットやスマートフォンでもプレイ可能
