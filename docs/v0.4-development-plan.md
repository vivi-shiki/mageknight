# Mage Knight Web v0.4 开发计划

更新日期：2026-10-08

## 1. 版本目标

`v0.4 Rules Coverage` 将 v0.3 的标准化数字效果升级为可追溯的逐实体规则层。范围仍是原版核心单人 Solo Conquest，不加入多人和扩展运行时。

## 2. 任务与完成判定

| 任务 | 交付物 | 完成判定 | 证据 |
| --- | --- | --- | --- |
| V04-01 规则清单 | 48 张市场牌、20 种唯一单位、36 项英雄技能 | ID 与 v0.3 牌池完全一致，无缺项、重复或占位文本 | ST-410、ST-411 |
| V04-02 Effect DSL | 选择、目标、法力、水晶、伤牌、轨道、单位、敌人、地形及特殊操作节点 | JSON schema 可递归校验，运行时只接受合法节点 | DSL 单测、TypeScript |

| V04-07 发布验收 | lint、类型、单测、属性测试、回放、E2E、构建 | `npm run test:acceptance` 全部通过 | v0.4 验收报告 |

## 3. 实现等级

- `full`：当前引擎完整执行清单中编码的语义，并有针对性测试。
- `modeled`：保留原规则文本与结构化效果；稳定的数值和通用部分可执行，复杂时序由语义化 `special.rule` 保留，等待后续专用子系统。
- 卡牌：16 `full`，32 `modeled`。
- 单位：17 `full`，3 `modeled`。
- 技能：9 `full`，27 `modeled`。

## 4. 技术约束

- 规则 JSON 是 v0.4 规则覆盖和来源引用的权威数据源。
- UI 不解释或复制规则，只展示内容并提交引擎生成的合法命令。
- 失败命令不得消耗法力、移动牌、单位状态或目标修正。
- v0.4 不承诺额外回合、旗帜附着、单位市场能力借用等复杂操作的最终语义。
- 美术继续只通过稳定 `assetAlias` 关联，可独立替换。

## 5. 不纳入

- Lost Legion、Krang、Shades of Tezla 和粉丝扩展运行时。
- 多人同步、服务器、账号和云存档。
- 官方图片分发与商业素材打包。
- 对 `modeled` 项目的完整时序状态机。
