# Mage Knight Web v0.5.0

发布日期：2026-10-08

## 新增

- 将原版核心 48 张市场牌、20 种唯一单位和 36 项英雄技能全部升级为完整规则条目。
- 支持多目标和嵌套选择、自由法力颜色、额外回合、特殊移动及动态战斗修正。
- 支持荣耀、恐惧、保护和勇气旗帜的单位附着、主动能力及生命周期。
- 页面新增活跃规则和单位附件状态。

## 兼容性

- 存档 schema 升级为 v5。
- v2、v3 和 v4 本地存档会自动迁移到 v5。
- 内容版本或内容 hash 不匹配的存档仍会被明确拒绝。
- 回放格式升级为 v5，并继续使用确定性命令和状态哈希。

## 当前限制

- 仅交付原版核心单人 Solo Conquest。
- 扩展和多人网络层不在 v0.5 范围内。
- 视觉素材仍为可替换占位资源。
