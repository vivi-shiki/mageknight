# Mage Knight Web v0.5 实现状态

更新日期：2026-10-08

## 已完成

- `v0.5-rules-manifest.json` 覆盖 48 张市场牌、20 种唯一单位和四名英雄共 36 项技能，所有条目均为 `full`。
- v5 内容校验器拒绝缺项、重复项、`modeled` 条目和没有运行时处理器的特殊规则。
- 命令协议支持多目标、数量、法力颜色、二级能力及二级目标选择。
- `ruleRuntime` 支持移动到攻击、特殊移动、招募修正、治疗/声望触发、单位全局加成、攻击转换、无限法力、时段规则和额外回合。
- 四类旗帜拥有独立附件状态；附件跨轮保留、每轮重置使用状态，并在单位摧毁或替换时弃置。
- 战斗动态读取物理攻击翻倍、抗性移除、工事忽略、成功格挡触发、单位护甲/抗性和声望触发。
- schema v5 保存运行时、附件和本回合伤牌；v2、v3、v4 存档均可迁移。
- 页面显示活跃特殊规则和单位附件，并保持极简居中排版。

## 保留边界

- 仍是单人 Solo Conquest；多人仅有可复用的确定性基础设施。
- 扩展内容尚未接入运行时，不能通过修改 JSON 直接启用。
- 市场牌和单位使用占位视觉，可按稳定 definition ID 替换素材。
