# Mage Knight Web v0.4.0

发布日期：2026-10-08

## 新增

- 原版核心市场牌、单位和英雄技能的结构化规则清单与来源引用。
- 可递归 Effect DSL，以及选择、目标、法力、水晶、伤牌、战斗修正和地形费用执行。
- 单位多能力和英雄技能的合法命令生成。
- 网页规则折叠区、实现级别、单位、技能和法力令牌展示。
- schema v4 存档、v2/v3 迁移和 replay v4。

## 兼容性

- v0.2 和 v0.3 征服存档在载入时迁移到 v4。
- v0.1 教学存档仍与征服模式隔离。
- 内容 hash 加入 v0.4 规则清单；不同清单的 v4 存档会被拒绝。

## 限制

- 32 张卡牌、3 种单位和 27 项技能标记为 `modeled`；其稳定通用效果可执行，复杂时序仍待专用规则子系统。
- 本版本仍仅支持本地单人游戏，不包含扩展运行时或网络多人。
