# Mage Knight Web v0.6 实现状态

## 已实现

- `lost-legion.official-v0.6` 内容模块：Wolfhawk、26 张一扩牌、16 张单位卡、9 项单人技能、22 类敌人、5 类地点和 6 个七格板块。
- 墙的额外移动费用、跨墙工事和忽略墙效果。
- 迷宫三条路径、指定水晶奖励、法术/神器奖励、深层矿井选色和难民营招募。
- Elusive 双护甲、Assassination、Cumbersome、Unfortified、多重攻击。
- 指挥旗帜、坚毅旗帜、Thugs/Heroes 声望费用、Delphana Masters 的获得限制和多能力激活。
- Volkare 营地揭示、难度军队规模、行动牌、移动、增援、传送门失败和击败军队胜利。
- schema v6 存档、v0.2-v0.5 征服存档迁移和 replay v6。

## 范围边界

本版本只实现单人玩法。合作技能、玩家间战斗、合作突袭与网络状态同步不进入 v0.6。卡牌与单位文本以仓库冻结的一扩结构化规格为运行依据；替换正式美术不改变规则 ID。
