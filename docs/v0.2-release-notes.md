# Mage Knight Web v0.2.0

## 新增

- 可配置 seed 与探索者/标准/老兵难度的单城征服开发场景。
- 昼夜战术、Dummy Player、轮末压力和市场刷新。
- 随机完整七格板块、隐藏敌人池和信息屏障。
- 高级行动、法术、单位和神器牌区，声望修正、升级与指挥槽选择。
- 七类基础地点、城市多守军、扩展敌人能力和分项终局计分。
- v0.2 IndexedDB 存档、撤销、恢复和带内容身份的回放导出。

## 兼容性

- v0.1 教学模式继续位于 `?mode=tutorial`。
- v0.1 教学存档不会无损转换为单城征服；导入时给出明确拒绝信息。
- 正式美术仍由 `assetAlias` 占位，可在不修改规则 ID 的情况下替换。

## 已知限制

- 这是开发场景，不是完整官方 Solo Conquest。
- 仅有 Tovak 和经过范围控制的内容批次。
- 不含多人、其他英雄、原版全牌池或任何扩展运行时。
