## 发布命令

```text
npm ci
npm run test:acceptance
```

`test:acceptance` 依次运行 typecheck、lint、单测、属性测试、回放、Chromium/Firefox/WebKit E2E 和生产构建。

## 已知边界

- 这是 First Reconnaissance Lite，不是原版完整教学场景。
- 只包含 Tovak、16 张基础牌、场景所需敌人/单位/奖励和两个七格板块。
- 不含多人、其他英雄、完整市场/城市、正式扩展或粉丝扩展运行时。
- 美术继续使用可替换 asset alias 和文字/色块占位。
- 存档 schema 为 1，仅兼容内容版本 `0.1.0`。
