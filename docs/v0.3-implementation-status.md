# v0.3 实现状态

更新日期：2026-10-08

## 结论

`v0.3.0` 已实现原版核心单人版本：可选择四名原版英雄，以 seed 和难度开始官方 Solo Conquest，探索 7 个乡村板块和 4 个核心板块，依次征服两座城市，并在目标完成后进行一个最后回合。

根路径运行 v0.3；`?mode=tutorial` 保留 v0.1 教学模式。

## 已实现

- Arythea、Goldyx、Norowas、Tovak 四套 16 张起始牌组。
- 非 Tovak 英雄各 9 项单人技能，以及 Tovak 既有技能线。
- 16 张高级行动、16 张法术、16 张神器、20 个普通单位和 20 个精英单位的原版核心清单。
- 官方 Solo Conquest 的 6 轮、楔形地图、7+4 板块、双城 5/8 和最后一回合规则。
- 城市征服进度、正式单人计分结构及难度城市等级配置。
- schema v3 存档、自动/手动保存、撤销、回放导出和 v0.2 迁移。
- 英雄、场景、难度、seed 配置，以及极简居中地图和操作面板。

## 兼容性

- v0.1 教学模式和 Golden Replay 保持可用。
- v0.2 单城征服存档会迁移到 schema v3，并保留单城回归场景。
- v0.1 教学存档不能转换为征服存档，导入时返回明确错误。

## 规则边界

核心组件身份和牌池组成已按本地 TTS 原版组件索引录入。高级行动、法术、神器、单位及英雄技能当前采用引擎支持的标准化数字效果，并非全部官方牌面文字的逐字实现。

扩展和多人没有进入运行时。多人仅保留技术方向：客户端提交命令，权威引擎产生事件并广播，随机源和隐藏信息只存在于服务端。

```text
npm run dev
```
