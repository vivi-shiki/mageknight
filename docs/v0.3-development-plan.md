# Mage Knight Web v0.3 开发计划

更新日期：2026-10-08

## 1. 版本定位

`v0.3 Core Complete` 把 v0.2 的单英雄开发场景升级为可配置的原版核心单人游戏。重点是建立完整、稳定、可替换美术的内容骨架，并实现官方 Solo Conquest 的地图、双城目标和最后一回合规则。

本版本的“Core Complete”指原版核心组件清单、四名英雄起始牌组、正式单人场景结构和现有规则引擎闭环完整。高级行动、法术、神器、单位和英雄技能采用引擎支持的标准化数字效果；逐张复刻全部官方牌面文字不在本版本承诺内。

## 2. 范围

### 纳入

- Arythea、Goldyx、Norowas、Tovak 四名原版英雄。
- 每名英雄各 16 张、与本地 TTS 组件索引一致的起始牌组。
- 官方 Solo Conquest：6 轮、楔形地图、7 个乡村板块、4 个核心板块、两座城市。
- 标准难度城市等级 5/8，以及探索者、老兵难度配置。
- 征服两座城市后恰好保留一个最后回合。
- 原版核心牌池清单：16 张高级行动、16 张法术、16 张神器、20 个普通单位和 20 个精英单位。
- 非 Tovak 英雄各 9 项单人技能；Tovak 沿用 v0.2 技能线。
- schema v3 存档、v0.2 单城存档迁移、回放身份和内容 hash。
- 极简居中 Web 操作层中的英雄、场景、难度和 seed 配置。

### 不纳入

- Lost Legion、Krang、Shades of Tezla 和粉丝扩展运行时。
- 多人、PvP、合作攻城和网络服务端。
- 官方素材分发、动画、音效、账号和云存档。
- 每张高级行动、法术、神器、单位和技能的逐字牌面语义。

## 4. 技术约束

- 内容 JSON 是组件身份、牌池组成和来源引用的权威数据源。
- React 只提交引擎投影出的合法意图，不在 UI 内复制场景判断。
- 引擎保持无 DOM、React、IndexedDB 和网络依赖。
- 随机牌序、地图、敌人和 Dummy 全部由 seed 驱动。
- 存档升级在边界层执行；运行中的引擎状态只接受 schema v3。
- 素材继续通过稳定 ID/alias 关联，可在不修改规则数据的情况下替换。

- [x] 两座城市按场景配置使用 5/8 等级，并计入 0/2 至 2/2 目标。
- [x] 第二座城市征服后恰好执行一个最后回合。
- [x] 原版核心市场和单位清单通过 schema、引用和数量校验。
- [x] v0.2 存档可迁移到 schema v3；v0.1 教学存档继续明确拒绝。
- [x] 四英雄/难度配置、完整七格板块和恢复流程可在网页操作。
- [x] v0.1 教学与 v0.2 规则回归测试通过。
- [x] TypeScript、ESLint、Vitest、属性测试、Golden Replay、Playwright 和生产构建通过。

## 6. 后续版本入口

`v0.4` 应优先建立牌面效果覆盖矩阵，再按规则风险分批实现官方卡牌的完整语义。扩展内容只能在核心效果 DSL 覆盖对应机制后启用，避免把扩展规则硬编码进 UI 或单个实体处理器。
