# Mage Knight Web v0.1.0

v0.1.0 是可独立运行的单人教学垂直切片：Tovak 使用固定基础牌组，在两块七格地图上探索、招募农民并完成两场四阶段战斗。引擎是纯 TypeScript 确定性状态机，React 页面只提交公开命令。

本版新增 IndexedDB 自动存档和一个手动槽、受信息屏障约束的撤销、JSON 日志导出、冻结内容 manifest、三浏览器 Playwright 测试和 100 seed 不变量门禁。

已知范围边界：不包含多人、完整 First Reconnaissance、其他英雄、完整市场/城市规则以及任何正式扩展或粉丝扩展内容；美术使用可替换 alias 和文字/色块占位。存档 schema 为 1，仅承诺兼容内容版本 `0.1.0`。
