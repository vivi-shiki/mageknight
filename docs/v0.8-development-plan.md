# Mage Knight Web v0.8 开发计划

## 目标

将 Shades of Tezla 的单人内容接入现有卡牌战棋内核，使其可与原版、Lost Legion、Krang 独立组合。多人、合作技能、玩家间战斗和网络同步不进入本版本。

## 工作包

### M8.0 状态与通用规则

- 状态升级到 schema 8，加入阵营、阵营奖励、地点覆盖物和独立首领转盘。
- 增加 Defend、Vampiric、Ambush、Pursuit 和同阵营召唤。
- 增加隐秘山谷、亡灵城、墓地的移动、昼夜、治疗、法力和封印规则。
- 完成条件：规则只能通过公开命令修改状态；存档、撤销和回放均包含新增字段。

### M8.1 内容包

- Braevalar：16 张基础牌、2 张替换牌、9 个单人技能、初始水晶。
- 两个阵营：32 枚敌人、24 枚一次性奖励、2 个十二级首领、3 个覆盖物。
- 内容由 JSON manifest 驱动，美术只通过 `assetAlias` 引用，后续可无规则改动地换图。
- 完成条件：schema/lint 通过；三种可选模块的八种组合哈希互异且无内容泄漏。

### M8.2 场景闭环

- 生与死、亡者国度、隐秘山谷、失落圣物四个单人场景。
- 首领布置、守卫、跨级伤害、墓地封印、遗物进度、最后回合和计分。
- 完成条件：每种目标有可达的胜负判定；Tezla 场景可从创建运行到 `game-over`。

### M8.3 发布与兼容

- 页面提供模块开关、英雄和场景选择，并显示首领、覆盖物与阵营奖励。
- v2-v7 存档迁移到 v8；v8 回放验证内容哈希和终局哈希。
- 为原版、Volkare、Krang、Tezla 保留 Golden Replay。
- 完成条件：`npm run test:acceptance` 通过，浏览器无控制台错误，生产构建成功。

## 技术边界

- 单机状态机仍是唯一规则真相，React 仅显示 `projectConquestView` 和提交命令。
- 随机顺序只来自带种子的 RNG；奖励弃牌堆重洗也纳入回放确定性。
- 美术不是 v0.8 验收项；当前 SVG 地图和无样式化文字承担可替换占位表现。
- 多人后续可在命令日志之上增加房间、席位、隐藏信息投影和服务端仲裁，不修改本版本规则实体格式。

## 发布门禁

1. TypeScript 与 ESLint 无错误。
2. 内容 schema、规则单测、迁移测试、属性测试全部通过。
3. 四条 Golden Replay 逐步哈希稳定，中点 JSON 恢复无分歧。
4. Playwright 覆盖模块选择、七格探索、存档、回放和发布视口。
5. Vite 生产构建成功，并在 `http://127.0.0.1:4173/` 完成实际浏览器复查。
