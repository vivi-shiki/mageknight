# Mage Knight Web v0.8.0 发布说明

## 新增

- 新英雄 Braevalar，以及两张专属替换牌和九个单人技能。
- Shades of Tezla 两个阵营的敌人、一次性奖励和十二级首领。
- Defend、Vampiric、Ambush、Pursuit 与阵营召唤规则。
- 隐秘山谷、亡灵城、墓地覆盖物和墓地封印。
- 生与死、亡者国度、隐秘山谷、失落圣物四个单人场景。
- 页面中的 Tezla 模块开关、目标进度、奖励库存和首领地图标记。
- 手机响应式布局：双列新局设置、区域快捷导航、独立窄屏地图视窗、横向手牌轨道和触控尺寸动作按钮。

## 兼容

- 征服存档升级为 schema 8；v2-v7 存档自动迁移。
- 回放升级为 replayVersion 8，并验证模块、内容哈希和终局哈希。
- 原版、Lost Legion 与 Krang 可单独启用，也可与 Tezla 组成全部八种组合。

## 范围

- 本版本只承诺单人规则闭环。
- 多人和合作技能保留数据/命令日志层面的扩展位置，不提供 UI 或网络实现。
- 卡牌和版图继续使用可替换占位表现，规则实体与素材通过 `assetAlias` 解耦。
