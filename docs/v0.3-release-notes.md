# Mage Knight Web v0.3.0

## 新增

- Arythea、Goldyx、Norowas、Tovak 四名原版英雄及各自的 16 张起始牌组。
- 官方 Solo Conquest：6 轮、7 个乡村板块、4 个核心板块、两座城市和目标完成后的最后一回合。
- 16 张高级行动、16 张法术、16 张神器、20 个普通单位和 20 个精英单位的核心牌池清单。
- 英雄和正式场景选择、双城等级/征服进度显示。
- schema v3 存档与 v0.2 单城征服存档迁移。

## 兼容性

- v0.1 教学模式继续位于 `?mode=tutorial`。
- v0.2 单城开发场景保留为回归场景，已有 v0.2 征服存档可迁移。
- 正式美术继续由稳定资源引用占位，可独立替换。

## 已知限制

- 高级行动、法术、神器、单位和英雄技能使用标准化数字效果，尚未逐张实现全部官方牌面文字。
- 不含扩展、粉丝扩展、多人、服务端、账号或云存档。
