# Mage Knight Web v0.5 开发计划

更新日期：2026-10-08

## 目标

`v0.5 Full Core Rules` 将 v0.4 中仍标记为 `modeled` 的原版核心单人规则升级为可执行规则。范围保持为单人 Solo Conquest；不增加扩展内容或多人服务。

## 工作包

| 工作包 | 范围 | 完成判定 |
| --- | --- | --- |
| V05-01 内容冻结 | 新建 v0.5 规则清单并升级 schema | 48 张牌、20 种单位、36 项技能精确覆盖且全部为 `full` |
| V05-02 选择协议 | 多目标、有序选择、数量和颜色选择、嵌套市场单位能力 | 每个选择可由合法命令完整表达，非法目标原子失败 |
| V05-03 持续规则 | 移动转换、地形模式、攻击转换、回合与轮次触发 | 效果在正确窗口生效并在规定边界清除 |
| V05-04 附件系统 | 四类旗帜、单位被动与主动能力、离场清理 | 附件跨轮保留，单位离场后进入弃牌堆 |
| V05-05 复杂牌面 | 额外回合、借用能力、免费招募、批量弃牌、治疗触发 | CT-510 至 CT-524 通过 |
| V05-06 存档迁移 | schema v5、v2/v3/v4 迁移、回放 v5 | 旧存档迁移后满足 v5 schema，重放哈希一致 |
| V05-07 页面接线 | 活跃规则、附件和 v0.5 状态显示 | React 与 Playwright 验收通过 |
| V05-08 发布门禁 | 类型、Lint、单测、属性、回放、E2E、构建 | `npm run test:acceptance` 完整通过 |

## 技术约束

- 规则清单只描述内容；状态变化由纯命令引擎处理，UI 不实现规则分支。
- 所有随机结果由状态 RNG 产生并进入事件/回放边界。
- 持续效果集中在 `ruleRuntime`，永久附着效果集中在 `attachments`。
- 复杂规则无法识别时立即失败，禁止静默忽略未知 `special.rule`。
- 多人只保留确定性命令日志、内容 hash 和状态投影接口，不在本版本交付网络层。

## 非目标

- 原版扩展、一扩、二扩、三扩及粉丝扩展的可玩内容。
- 联机房间、服务器权威、匹配、观战与断线重连。
- 官方美术资源复刻；当前素材仍可通过稳定内容 ID 替换。
