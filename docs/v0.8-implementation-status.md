# Mage Knight Web v0.8 实现状态

## 已完成

- 内容：Braevalar、2 张替换牌、9 个技能、22 种共 32 枚阵营敌人、12 种共 24 枚阵营奖励、2 个十二级首领、3 个覆盖物、4 个单人场景。
- 规则：Defend、Vampiric、Ambush、Pursuit、同阵营召唤、奖励获取与弃置、同名奖励每回合一次。
- 地图：城市自动替换为隐秘山谷或亡灵城；亡者国度把魔法林地转换为墓地；覆盖物拥有独立解放和封印状态。
- 首领：独立等级、守卫、攻击/抗性、一次攻击跨越多个等级、逐级名望和击败计数。
- 场景：阵营首领、死灵法师与墓地、遗物三类新目标进入统一终局和计分流程。
- 持久化：schema 8、v2-v7 迁移、模块身份检查、回放版本 8 和终局哈希校验。
- 页面：Shades of Tezla 开关、Braevalar/场景选择、覆盖物/首领地图标记、目标与阵营奖励状态。

## 数据与素材

- 规则来源为本地官方 Shades of Tezla 规则书及本地 TTS 模组组件索引。
- 所有新增实体保留 `sourceRef` 和 `assetAlias`；规则代码不依赖图片文件名。
- 当前界面继续采用极简 HTML 与基础 SVG 六边格，正式卡图和版图贴图可后续替换。

## 保留范围

- 未实现多人、合作技能、玩家间战斗、网络房间和隐藏信息同步。
- 自动策略只用于确定性失败终局回归，不是游戏 AI，也不代表场景平衡。
- 规则书未提供机器可读首领转盘数据；转盘数值已固化进 manifest，并由 schema 与回放锁定，后续若发现勘误只需改内容版本。
