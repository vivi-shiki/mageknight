# Mage Knight Web v0.7 实现状态

## 内容模块

- 原版核心始终启用。
- `lost-legion.official-v0.6` 与 `krang.character-v0.7` 可分别开关，也可同时启用。
- 英雄、场景、牌、技能、单位、敌人、地点、板块、市场牌库与敌人池均按模块构建。
- 内容哈希仅包含实际启用的模块；新游戏、存档和回放保留同一模块组合。

## Krang

- 新英雄 `krang.hero.krang`，起始护甲 2、手牌上限 5、指挥槽 1。
- 16 张起始牌严格按组件清单组成，包含专属牌“无情胁迫”和“野蛮收割”。
- 9 个单人技能进入升级池：诅咒、奥术伪装、傀儡大师、身经百战、再生、萨满仪式、混乱大师、灵魂向导、战斗狂乱。
- 合作技能 Mana Enhancement 不进入单人技能池。

## 规则运行时

- `FlipBackSkill` 由技能数据声明翻回条件：休息、消耗行动、支付绿色法力。
- 每回合技能使用状态与每轮技能状态分离；翻回不会绕过“每回合一次”。
- 已实现休息、弃牌收割水晶、单位招募折扣与声望代价、低等级单位整备、敌人攻击/护甲诅咒、伤害减免、移除伤牌、混乱颜色轮转和敌人傀儡存取。
- 傀儡大师只读取敌人的攻击、护甲和元素，不复制敌人能力；与扩展 FAQ 一致。

## 存档

- 征服状态与存档 schema 升级到 v7，应用与内容版本为 `0.7.0`。
- v2-v5 存档按原有 Lost Legion 基线迁移；v6 存档保留其模块组合并迁移技能状态。
- v7 载入时根据存档模块重建内容并校验哈希，避免用错误内容组合继续游戏。

## 范围边界

- 多人、合作技能、玩家间战斗和网络同步仍不在当前范围。
- 美术继续通过 `assetAlias` 解耦，可替换而不改变规则 ID 或存档结构。
