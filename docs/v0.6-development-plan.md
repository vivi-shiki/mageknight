# Mage Knight Web v0.6 开发计划

## 目标

`v0.6 Lost Legion` 在 v0.5 原版单人规则运行时上加入一扩的单人可玩内容。美术仍通过 `assetAlias` 解耦，当前页面使用极简 HTML 与程序化六角地图。

## 交付批次

| 批次 | 内容 | 完成判定 |
| --- | --- | --- |
| V06-01 | 一扩内容模块与 schema | Wolfhawk、26 张牌、16 张单位卡、敌人、地点和板块通过内容 lint |
| V06-02 | 地图与地点 | 墙、迷宫/大迷宫、深层矿井、难民营可执行 |
| V06-03 | 战斗规则 | Elusive、Assassination、Cumbersome、Unfortified、多重攻击和双重工事可执行 |
| V06-04 | 单位与旗帜 | 特殊招募费用、指挥旗帜、坚毅旗帜和一扩单位限制进入运行时 |
| V06-05 | Volkare | 营地、军队牌库、移动、增援和单人胜负闭环可执行 |
| V06-06 | 发布门禁 | schema v6、旧存档迁移、回放、测试、构建与浏览器验收通过 |

## 非目标

- 多人网络同步、合作突袭和 PvP。
- Wolfhawk 的合作技能 Howl。
- 最终商业美术；所有视觉资源仍可通过别名替换。
