# Mage Knight Web v0.4 实现状态

更新日期：2026-10-08

## 已完成

- 新增 `v0.4-rules-manifest.json`，覆盖 48 张市场牌、20 种唯一单位和四名英雄共 36 项技能。
- 每个规则实体包含稳定 ID、规则文本、来源引用、EffectNode 和 `full`/`modeled` 标记。
- Effect DSL 支持资源、法力、抽弃牌、选择、条件、持续效果、水晶、伤牌、轨道、单位目标、敌人修正和地形费用。
- 卡牌、技能和单位统一通过同一个结算器；合法动作自动展开选择分支及目标。
- 战斗已读取敌人护甲、攻击、工事、抗性和跳过攻击修正；移动已读取临时地形费用。
- 法力令牌和敌人修正进入 schema v4；v2、v3 存档可迁移。
- 网页以极简折叠文本展示规则、来源和实现级别，并显示单位、技能及法力令牌。

## 已知边界

`modeled` 项目中的额外回合、旗帜附着、动态敌人数加成、成功格挡后的延迟触发、单位市场能力借用和批量转换仍由 `special.rule` 保留语义标识。它们不会被 UI 标示为完整实现。

多人模式仍未进入运行时。未来实现可复用确定性命令日志、内容 hash 和状态投影，加入房间服务、服务器权威校验与断线重连。
